# tsumiki プライバシーポリシー

制定日: 2026年8月29日 / バージョン: 1

この文書は、tsumiki（以下「本サービス」）が利用者の情報をどのように取り扱うかを
説明するものです。利用条件そのものは利用規約を参照してください。

## 1. 取得する情報

- Google アカウント情報 ログイン時に、Google アカウントのメールアドレス・表示名・アイコン画像を取得します。これは Firebase Authentication による Google サインインを通じて行われます。
- 入力データ かぞくの名前、やること、実績の記録、コメント、コインの記録など、
  利用者が本サービスに入力したデータ。
- 写真 pro プランの実績報告に添付された写真（Firebase Storage に保存）。
- 端末・ブラウザの信号 不正なリクエストを見分けるため、Firebase App Check（reCAPTCHA Enterprise）が接続元の端末・ブラウザに関する情報を Google に送信し、正当なリクエストかどうかの判定を受け取ります。これは本サービスの操作内容や入力内容そのものを収集するものではありません。

現時点で、本サービスは広告配信や利用状況分析のためのアクセス解析・トラッキング Cookie を使用していません。将来これらを導入する場合は、この文書を改定し、利用規約
の変更手続きに従って利用者に案内します。

## 2. 利用目的

取得した情報は、次の目的にのみ利用します。

- 本サービスの機能（かぞくのメンバー表示、やることの管理、コインの計算、
  ランキング表示など）を提供するため
- 不正利用・自動化されたアクセスからサービスを守るため
- 不具合の調査やお問い合わせへの対応のため

## 3. 共有される範囲

- 入力データ・写真は、同じかぞくに属するメンバーの間でのみ共有されます。他の
  かぞくのデータが見えることはありません。
- 広告配信や第三者へのデータ販売は行いません。
- データはすべて Google Cloud / Firebase 上に保存されます。データの保管・処理は Google のインフラに委託していますが、閲覧・利用の目的は本サービスの提供に限られます。
- 運営者は、サービスの維持・不具合対応に必要な範囲でデータにアクセスすることが
  あります。この管理者アクセスは、あらかじめ登録されたメールアドレスに限られ、
  かぞくの名前・プラン・やることの数・メンバー数・作成日のみが対象です。実績・
  コメント・写真など、メンバーが書いた内容そのものにはアクセスできません。

## 4. 保存期間と削除

- データは、かぞくが存在するあいだ保存されます。
- かぞくの「おや(かんりにん)」がかぞくを削除すると、そのかぞくに属するすべての
  データ（やること・実績・コメント・コインの記録・写真を含む）が削除され、
  復元できません。
- 実績の記録が取り消された場合、添付されていた写真も削除されます。
- Google アカウントとの連携解除やアカウントデータの完全な削除を希望する場合は、第6条の連絡先までご連絡ください。

## 5. お子さまの情報について

本サービスは家族で使うことを前提としたアプリです。こどもの役割で入力される
やること・実績・コメントは、そのこどもが属するかぞくの中でのみ表示され、
かぞくの外部や他のかぞくに共有されることはありません。こどものアカウントの
作成・招待は、かぞくの「おや」が行います。

## 6. お問い合わせ

本文書や本サービスの情報の取り扱いに関するお問い合わせは、運営者まで
（連絡先は準備中です。追ってアプリ内でご案内します）。

## 7. 改定

運営者は、必要に応じてこの文書を改定することがあります。取り扱う情報の範囲を
実質的に広げる改定を行う場合は、アプリ内で案内します。
